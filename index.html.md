# OkayCoolWowEtc - Mixed Media Art

OkayCoolWowEtc is a Budapest, Hungary based mixed media art portfolio. The works combine acrylic painting with fuse bead elements on canvas, panel, and other surfaces.

## Gallery

The homepage contains the full artwork gallery. Each artwork card includes:

- artwork image
- artwork title
- dimensions
- material description
- sale or stolen status where applicable

The gallery can be filtered by size. Opening an artwork shows a larger image and its title and material details.

## Exhibitions

The site includes a compact exhibition section for public showings.
